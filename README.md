# Exercici 2: Introducció a Markdown

## Descripció
Aquest document és una **prova** de la sintaxi bàsica de *Markdown*. L'objectiu és aprendre a estructurar informació i poder convertir-la a HTML o PDF fàcilment.

### Objectius
- Aprendre la sintaxi bàsica de Markdown
- Convertir Markdown a HTML
- Generar un PDF a partir d'un fitxer `.md`


## 1. Èmfasi i estils de text

- **Negreta**: `**text**`
- *Cursiva*: `*text*`
- ~~Ratllat~~: `~~text~~`
- `Codi en línia`: `` `codi` ``
